# CSS Position Property Practice

This project is a simple HTML and CSS practice project to understand different CSS `position` properties.

## 📌 About

The project demonstrates how the following CSS positioning properties work:

* `relative`
* `absolute`
* `sticky`
* `fixed`

Each box uses a different positioning method so that their behavior can be observed while moving and scrolling the webpage.

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📂 Project Structure

```text
project-folder/
│
├── index.html
└── styles.css
```

## 🎯 Concepts Covered

### 1. Relative Position

`position: relative` allows an element to move from its original position while keeping its original space in the document.

### 2. Absolute Position

`position: absolute` removes an element from the normal document flow and positions it relative to its containing block.

### 3. Sticky Position

`position: sticky` behaves like a normal element until it reaches the specified position while scrolling.

### 4. Fixed Position

`position: fixed` positions an element relative to the browser viewport and keeps it in the same position while scrolling.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.
4. Scroll the page to observe the `sticky` and `fixed` positioning behavior.

## 📚 Learning Objective

The main objective of this project is to understand and practice CSS positioning concepts through a simple visual example.
